Reproduce

The Docker image builds the packaged Pluto sources, the Rocq proofs, and the extracted compiler, then runs the selected compiler and executable checks.

Build and Run

From the extracted archive root:

docker build -f environment/Dockerfile -t polcert-artifact .
docker run --rm polcert-artifact

The build needs network access to Ubuntu and opam package repositories and an x86-64 Docker environment. On the preparation machine, a cold build took about 40 minutes and the default checks took about 31 minutes. The final image was about 2.1 GB; cache state and hardware will change these values.

On an ARM host, add --platform linux/amd64. For a low-memory build, reduce PLUTO_BUILD_JOBS, PROOF_JOBS, or BUILD_JOBS with Docker build arguments.

Test Modes

Command Expected work
docker run --rm polcert-artifact Run 25 compiler and executable checks.
docker run --rm polcert-artifact full Run all 30 artifact checks.
docker run --rm polcert-artifact proof Clean and rebuild every proof and the extracted compiler.
docker run --rm polcert-artifact bugs Run the seven focused Pluto reliability cases.
docker run --rm polcert-artifact ci Run all seven CI test groups in sequence.
docker run --rm polcert-artifact all Run the full artifact and all CI test groups.

A successful run ends with the selected checks marked PASS and exits with status 0. The environment guide lists the same modes and resource controls.

Proof-Only Build

For a host-side build, install the toolchain specified in environment/Dockerfile, then run: 

cd source
./configure x86_64-linux
make depend
make proof
make check-admitted
make extraction

This rebuilds all Rocq files, checks for unfinished proofs, and extracts the OCaml compiler. The recorded proof report covers 197 Rocq files and reports zero admitted markers, zero aborted proofs, zero unrealized extraction axioms, and zero missing public-route theorems.
