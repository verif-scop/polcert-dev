End-to-End Verified Polyhedral Compilation

PolCert accepts a bounded loop program and proposed loop optimizations. It checks each transformation and generates a sequential or parallel target loop only when the checks succeed.

What PolCert Does

A polyhedral optimizer searches for profitable execution orders and loop shapes. PolCert checks the proposed schedule, tiling, and parallel loops against the program's iteration domains and memory accesses. The main theorem covers the complete path from the source loop to the generated target loop.

Accepted compilation guarantee.

Every execution of the generated program matches an execution of the source program from the same input and produces the same result.

Scope

The theorem covers accepted structured-loop compilations through the generated sequential and parallel loop semantics. Parsing, printing, the optimizer's search algorithm, the external C compiler, and transformations that change storage or add or remove statement instances remain outside the theorem. PolCert may reject a legal proposal that its checks cannot establish.
