Correctness Statement

The main result is refinement. If compilation accepts a source loop, every target execution has a matching source execution from the same initial state. The two executions produce equal final states.

compile cfg source = Okk target

ParallelLoop.semantics target input target_result

implies

exists source_result, Loop.semantics source input source_result

and State.eq target_result source_result

Parallel loops use interleaving semantics: iterations may interleave while preserving the order inside each iteration. The proof covers all such target executions after a selected loop passes the independence check.
