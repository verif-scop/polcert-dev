Performance Comparisons

A separate whole-C campaign compared the unoptimized and accepted programs for 62 kernels. All 62 produced matching results. The search selected a non-identity route for 47 kernels and emitted a parallel output for 19. Each kernel links to its complete before/accepted program pair and exact run configuration.

Kernel Selected checked route Baseline Accepted output Speedup

Each candidate was timed once in the recorded search, so these numbers show observed end-to-end behavior rather than a stable benchmark ranking. The complete report lists every kernel, route, runtime, and full program pair.

Recorded Configuration

The campaign used the perf parameter tier, one baseline run and one accepted-output run per candidate, and cc -O3 -std=c99. Parallel outputs were compiled with -fopenmp and run with four threads. Each kernel page records its parameter values and selected polopt options.

Rejected Optimizer Proposals

Seven focused cases cover four confirmed Pluto miscompilations, one unsafe Pluto control interface, one historical fork regression, and one non-certifiable parallel hint that is not classified as a Pluto defect.

The rejection report states, for each case, the violated condition, the optimizer source of the proposal, and whether PolCert rejected the complete output or kept a certified subset. The linked bug-report draft includes reproduction commands and root-cause analysis.
