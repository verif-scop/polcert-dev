# Archive

This directory contains material removed from the active PolCert v9 workspace
without deleting its history.

- `development-history/`: former root recovery logs and plans tied to earlier
  container-side development.
- `proof-plans/`: completed extractor and code-generation proof plans.
- `docs/`: superseded implementation notes, design documents, and recorded
  possible bugs.

Generated baseline evidence, obsolete prototypes, retired skills, and the
storage-generalization copy were deleted from this tree. They remain available
from Git history or their dedicated branches. Archived files do not control
current claims or build instructions. Restore a file to the active workspace
only after checking it against the frozen v9 source and current paper contracts.
