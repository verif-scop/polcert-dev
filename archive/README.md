# Archive

This directory contains material removed from the active PolCert v9 workspace
without deleting its history.

- `development-history/`: former root recovery logs and plans tied to earlier
  container-side development.
- `proof-plans/`: completed extractor and code-generation proof plans.
- `docs/`: superseded implementation notes, baseline evidence, and design
  documents.
- `tools/`: host-side Pluto prototypes and diagnostic scripts replaced by the
  frozen implementation and artifact suites.
- `research/storage-generalization/`: a separate storage-changing research
  project outside the state-preserving v9 paper.
- `skills/`: retired agent workflows tied to old containers or completed tasks.

Archived files do not control current claims or build instructions. Restore a
file to the active workspace only after checking it against the frozen v9 source
and current paper contracts.
